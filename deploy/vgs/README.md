`sandbox.pem` is VGS's public self-signed CA for `*.sandbox.verygoodproxy.com`, copied verbatim from https://docs.verygoodsecurity.com/vault/http-proxy/outbound-connection (Code Samples). The same PEM is embedded in the valet binary (`internal/edge/card/vgs_sandbox.pem`) so sandbox works without `VGS_CA_FILE`; for `VGS_ENV=live` download `live.pem` from the VGS dashboard's Code snippets section and point `VGS_CA_FILE` at it.
